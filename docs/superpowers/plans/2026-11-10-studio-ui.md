# Studio UI Hybrid Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle Tab PDF as a dark hybrid Streamlit studio (upload, progress, result) without changing the transcription pipeline.

**Architecture:** Pure HTML/CSS helpers under `ui/` inject a studio theme and render non-interactive chrome. `tab_pdf.py` keeps Streamlit for inputs, session, and pipeline. `player_bar.player_html` adopts the same tokens. Existing result helpers stay.

**Tech Stack:** Python 3.11, Streamlit, existing `audio_to_tab` helpers. No new packages.

**Spec:** `docs/superpowers/specs/2026-11-10-studio-ui-design.md`

## Global Constraints

- Python `>=3.10,<3.13`. Do not add a dependency.
- Local only. Keep Experimental warning and public-YouTube disclaimer.
- Own tokens only: `#0f1115`, `#171a21`, `#2a2f3a`, `#e8eaef`, `#9aa3b2`, `#e8a317`.
- No MusicXML, LilyPond, GP5, login, upgrade, or competitor brand CSS.
- Do not commit unless the user asks.
- Leave `isolate.py`, `roformer.py`, `scnet.py`, `hardware.py`, and CLI paths alone unless a test requires an import.

## Review Focus

- Failed conversion still clears downloads via `record_failure` — keep `test_page_keeps_current_guards_and_clears_failed_downloads`.
- Player HTML still embeds speeds `0.25`/`0.50`/`0.75`/`1` and dark studio classes — add `test_player_html_uses_studio_tokens`.
- Progress card marks Done/Working from checklist rows — add `test_progress_card_html_renders_states`.
- Theme inject exposes CSS variables and hides Streamlit chrome clutter without removing page guards — add `test_studio_theme_defines_tokens`.
- Advanced settings remain reachable (`key="tab_separate_stems"`, Safer length) after layout rewrite — extend page-source guard test.
